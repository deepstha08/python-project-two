# 🎬 Story Video Studio

Type a story → get an animated video with talking cartoon characters, real voices,
lip-sync, TikTok-style word-by-word captions, scene backgrounds and music.
Vertical 1080×1920, ready to upload to TikTok, Instagram Reels and YouTube Shorts.

## Install & start (one double-click)

**Windows**
1. Install Python from https://www.python.org/downloads/ — **tick "Add python.exe to PATH"** during install.
2. Unzip this folder, then double-click **`start_windows.bat`**.
3. The first start installs everything (a few minutes, only once). Your browser then opens the app.

**Mac / Linux**
1. Install Python 3.10 or newer.
2. In a terminal inside this folder run: `bash start_mac_linux.sh`

Next time, just double-click / run the same file again. Videos are saved in the **`outputs`** folder.

> Internet is needed for the natural-sounding voices (free Microsoft neural voices).
> Without internet, Windows uses its built-in voice instead.

## How to use

1. **Type your story** in the big box. Three options:
   - **A short idea** + turn on the **AI writer** → it writes a full script with dialogue at your chosen length.
   - **A normal story** → quotes (`"Hi!" said Mia`) become dialogue, the rest is told by the narrator.
   - **A script** (full control, no AI needed):
     ```
     TITLE: The Dragon Egg
     [SCENE: park, day]
     Narrator: One sunny morning, Mia found something strange.
     Mia (surprised): Leo, look! Is this an egg?
     Leo (happy): That's the biggest egg I've ever seen!
     ```
     - Places: `room, kitchen, park, city, school, office, beach, forest, space, cafe`
     - Times: `day, sunset, night`
     - Emotions (face + voice change): `happy, excited, sad, angry, surprised, scared`
2. **Pick a length**: 1, 3, 5, 8, 10 or 15 minutes.
3. *(Optional)* **Characters**: type a name exactly as in the story, then choose a look (man, woman, boy,
   girl, old man, old woman), a voice, and/or **upload a face photo**. Characters you don't set up get an
   automatic cartoon look and their own voice.
4. Click **Generate video**. Download it from the player (or the `outputs` folder) and upload it.

## AI writer (for long videos from short ideas)

A 1-minute video needs about 150 spoken words, 15 minutes about 2,250. If you don't want to write that
much, let an AI do it. Choose a provider in the *AI writer* box:

| Provider | Cost | What you need |
|---|---|---|
| **Claude** | pay per use | API key from console.anthropic.com |
| **OpenAI** | pay per use | API key from platform.openai.com |
| **Ollama** | free | install from ollama.com, then run `ollama pull llama3.1` |

Click **"Write the script with AI first"** to see and edit the script before making the video.
If your text is already in script format, the AI is skipped and your script is used as written.

## Tips for views on TikTok

- Put a **hook** in the *Title* box ("She found a DRAGON egg 😳") — it shows in the first 3 seconds.
- 1-minute videos get the most completions; use 3–15 min for series and "storytime" content.
- Set the *End screen text* to "Follow for part 2!" and split long stories into parts.
- The built-in music is generated by the app, so there are no copyright strikes.
  Better still: upload without music and add a trending sound inside TikTok.

## Rendering time

Roughly 1–2× the video length on a normal laptop at 1080p (a 15-minute video takes ~20–30 minutes).
Pick **720×1280 (faster render)** for quick tests. Voices are cached, so re-making a video is faster.

## Honest limits

This app makes stylized 2D cartoon videos (the popular "animated story" format). It does not make
photorealistic AI-generated movies like Sora or Veo — those need paid cloud services. Photo faces are
animated in a cut-out "talking photo" style (moving jaw), not deep-fake style.
